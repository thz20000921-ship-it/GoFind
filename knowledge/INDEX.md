# 按问题找方法

这里是导航，不是必经流程。先判断用户要完成什么，只读相关方法和平台卡；把方法用在实际证据、决定或成品上。简单改稿通常只需一份方法，复杂跨平台判断才扩展。

| 当前问题 | 优先读取 | 应产生的实际工作 |
| --- | --- | --- |
| 谁最需要、为何付费、需求是否成立 | [用户与需求](methods/market-users.md) | 从原始讨论/访谈/经营记录识别情境，区分意向与行为 |
| 去哪里找客户、哪个渠道值得投入 | [渠道选择](methods/channels.md) | 比较真实可触达用户、转化路径、成本，明确优先取舍 |
| 关键词值不值得做、SEO/GEO 机会 | [搜索意图](methods/search-intent.md) + [搜索平台](platforms/search.md) | 原生搜索或自有查询调查，匹配内容，提出可检验机会 |
| 同行在做什么、产品怎样定位 | [竞品与定位](methods/competitors.md) | 可回查的同行观察、差异和可证明的价值表达 |
| 今天做什么选题、改标题/封面/脚本 | [内容制作](methods/content.md) + 对应平台卡 | 直接交付适合该场景的内容成品或修改稿 |
| 为什么没咨询/购买、如何表达信任 | [转化诊断](methods/conversion.md) | 检查完整路径并修正一个有证据的障碍 |
| 定价、卖点价值、能否承担获客成本 | [定价与经营](methods/pricing.md) | 同口径报价比较、成本约束和可兑现的报价草稿 |
| 哪个渠道/内容更有效、怎么解释增长 | [数据与归因](methods/measurement.md) | 核对口径与客户质量，区分归因和增量 |
| 值得测什么、多少结果才够、如何复盘 | [实验与学习](methods/experiments.md) | 适合实际流量和风险的测试、真实结果与下一动作 |

## 根据平台改变调查对象

| 平台/场景 | 读取 |
| --- | --- |
| 小红书：搜索、笔记、评论与咨询 | [小红书](platforms/xiaohongshu.md) |
| 抖音：推荐、搜索、内容到商品/服务 | [抖音](platforms/douyin.md) |
| 微信视频号、公众号、社群：关系、内容与可追踪转化 | [微信生态](platforms/wechat.md) |
| 本地服务：范围、价格、预约、履约与核销 | [本地生活](platforms/local.md) |
| 电商：规格、交易、退款、贡献 | [电商](platforms/ecommerce.md) |
| 搜索引擎和 AI 搜索：网页可见性与业务结果 | [搜索](platforms/search.md) |
| GitHub、开发者论坛、Reddit 等社区 | [社区与软件](platforms/communities.md) |
| B站、知乎、微博及其他未建立专卡的平台 | [新平台调查](platforms/new-platform.md)，按实际触发方式适配 |

平台不是白名单；业务更适合线下合作、转介绍或其他渠道时同样可以调查。平台卡不会替代当次规则核查，也不宣称掌握推荐权重。

## 判断依据与维护

[来源登记](sources.md) 区分相关正文已核查、摘要线索、无法读取；[案例迁移](cases.md) 展示怎样从原始案例提取有边界的方法；[研究取舍](research-notes.md) 解释哪些做法经过交叉核查、哪些被排除。
