# 搜索引擎、SEO 与 AI 搜索

**使用场景**：用户主动搜索问题、产品比较或本地需求；业务拥有或能够制作真正回答问题的内容。先核对目标地区/语言使用什么引擎，不默认 Google 覆盖全部用户。

**已核查基础**：[S03](../sources.md#s03) Trends 的相对兴趣，[S04](../sources.md#s04) Search Console 的自有表现，[S05、S06](../sources.md#s05) Google AI 搜索说明。Google 表明基础 SEO 仍适用，不能据此保证任一页面被引用，更不能当其他引擎的规则。

## 真实调查与执行

用目标语言、地区和任务词观察实际结果与意图，记录时间/地点/设备条件和打开的来源。查询结果数、`site:` 命中或外部工具排名不是完整索引/流量数据。自有 Search Console 只反映该资产的可报告表现，也不是市场总搜索量。

有网站权限时先检查相关页面是否能被访问/索引、主要内容是否可读、标题与正文是否回答用户问题、关键链接/移动端体验是否有效。技术改动仅在真实问题需要时做，不能为了 SEO 检查清单先重建网站。

制作可以验证的一手经验、完整步骤、适用/不适用、同条件比较和明确报价条件。引用来源只支持相应说法，结构清楚方便用户理解；不以批量改写常识、堆关键词或为每种同义查询造一页替代价值。没有独立证据不宣称某个文件、结构或“实体秘诀”必能提高 GEO 排名。

## AI 搜索怎样测量

围绕实际购买/使用任务选一个有依据的问题集，包含泛品类、具体场景、比较和限制条件。对每次实际查询保留引擎/产品、模式、时间、地区/语言、完整问题、账号个性化影响和可回查回答。只测试实际可用界面或合规 API，不能假设 API 与 UI 相同。

区分被提及、被引用、被推荐与事实表述准确。打开引用原页检查是否真的支持相邻主张；引用自己不自动表示正确推荐。复查出现/缺失的变动，单次回答只是样本，不给全市场“AI 排名/份额”。没有实际运行引擎就不能说已经测试 GEO。

Google 官方页面说明其 AI 功能数据纳入 Search Console 的总体 Web 表现，不能从普通报表编造单独 AIO 转化。其他工具的 AI 引荐、品牌搜索和直接访问可能只看到部分路径；以真实使用/客户质量和经营结果衡量，不只追引用次数。

## 验证与交付

交付有意图依据的页面/内容修改或完整草稿，并设置与发布成熟期相称的观察：能见性 → 点击/合格访问 → 使用/咨询/购买。已获授权的内容改动与索引核查可执行，公开发布和费用按授权。缺站点/后台时完成公开调查与稿件，明确未验证收录、引用和业务效果。
