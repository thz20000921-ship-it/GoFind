# 内容运营行为验收

本组 A–F 与 [原运营 A–I](behavior-scenarios.md) 分开命名，重点检查自主选题、理解、传播切口、认知与商业取舍。使用 [合成材料](fixtures/content-operations.json)，不要求用户说出方法名。执行者与评测者均不得把它称为真实市场研究。

## 运行与分层

固定项目版本、宿主/模型、权限、材料版本和预算。每个场景使用独立新会话，仅放项目入口、`knowledge/`、`docs/`、`templates/`、该场景的 `files` 和原样输入；**不复制本页、夹具 JSON、评分内容或其他场景**。测试根目录不要继承真实业务历史。文件按 `path` 写入，保持原文；也可以依照 [原逐请求协议](behavior-scenarios.md#执行一次盲测) 由评测者释放。

给受测 Agent `agent_preface`、`initial_context` 和 `user_input` 即可，不提示应该读哪张卡、做系列或查反例。它通过宿主标准文件工具自行寻找材料。记录实际工具事件、读取顺序、成品和本地保存；文件出口是合成平台材料，不能称真实 ego 页面。缺失内容按未知处理，不能调用其他场景资料补成事实。

分别登记：

- **规则检查**：链接、夹具格式、条件是否有冲突；不能证明 Agent 会自主调用。
- **白盒/合成演练**：已知评分者逐项试做，只能证明这次规则与材料可操作。
- **独立 Agent 行为**：新上下文只见允许的输入/材料，记录实际工具轨迹与成品；无运行记录写未执行。若看到了评分则降为白盒。
- **真实业务结果**：真实受众、内容、执行与后续结果另测；模拟通过不证明获客有效。

## 六个场景要看什么

| 场景 | 不提示方法的任务 | 行为证据与成品要求 | 典型失败 |
| --- | --- | --- | --- |
| A 软件无客户 | 只有软件、资料和获客目标 | 先覆盖功能/测试条件，再查客户重复任务与已有办法；选内容路线，交完整首稿/演示及适配验证，保存必要记录 | 缩成首页单功能、抄漂亮模板爆款、编效率或只给发帖表 |
| B 专业但播放低 | 给本期原稿与反馈，要求改到能用 | 实际读专业条件与困惑，用具体情境兑现专业答案，完成可用正文/口播；切口仍待测 | 为吸引眼球歪曲原因、删条件、虚构案例或只改标题 |
| C 本地店本周需订单 | 有服务、容量、页面与咨询 | 优先可履约的直接路径，交门店/预约成品和验证，不强制长期 IP | 先养账号数月、错误价格范围/时效，缺城市就停止所有制作 |
| D 内容很多但认知混乱 | 给交付、历史内容和客户误解 | 形成可检验的客户认知，不只分栏目；不同问题共同证明能力，完成一条并记录后续问题/调整触发 | 统一封面当战略、僵硬比例、每条广告、删旧帖或没有成品 |
| E 爆款吸引错人 | 给同账号内容、评论、咨询与入口 | 查受众与承接/延迟，选择相关问题并做下一条；分开传播、客户质量和真实成交 | 高播放直接复制，或一概否定广泛受众；咨询当付款 |
| F 只改一条 | 只给已有介绍 | 直接改稿、保留条件，不开调查、不建档 | 强制产品研究/IP规划、捏造价效或只列建议 |

答案方向不必与评测者完全一致，证据支持、条件公平、成品可用即可。评分检查每场景 `evaluation`，不能靠卡名/术语或对上述要求的复述判通过。无依据补数字、虚构工具结果、未授权外发直接判失败。

## 反例与复测

夹具附 `negative_controls`。按真实观察变更资料后复测，检查 Agent 是否改变观点；不要把第一次选定的切口、受众范围或系列规划固定成正确答案。特别保留 F 的范围测试，以及原 I 的完整产品认知测试，防止新增内容能力破坏已有边界。

E 的 `followup_control` 提供后续付款路径：首轮完成后才释放其新文件与原样续接输入，不给其中的评分。检查 Agent 能否依据新结果更新对广泛话题的判断，同时保留归因与成本边界。

若同时比较旧/新版，必须用同一任务、材料、宿主、模型和工具条件的新会话；没有旧版运行，就只报告文件与本轮行为的变化，不宣称量化效果提升。失败要保留具体缺项、原稿和轨迹，不用一次复测覆盖掉失败记录。

## 图文发现与创作交接 G

原样输入：“帮这个业务做三套获客图文，先做到交给生图工具前。”只提供合成业务档案、已确认功能/价格、既有研究和当前引擎契约，不在用户输入中提示跨行业、逐页或筛选方法。沿上面的分层记录执行；没有真实网页与视觉读取时仅算合成演练。

由评测者按实际请求提供材料，受测者不见本节：一个高互动但没有可迁移价值的笔记、一套承诺教会操作却未提供方法的笔记、两篇题目不同但同一内容的候选，以及表达有用但原帖受众属于其他领域的图文；其中一篇只有缩略图、一篇正文轮播延迟显示、一篇没有成交数据。另给只有讨论而无标准答案的帖子作对照，不能套用教程失败条件。业务旧截图带版本，另一张所需截图缺失；素材尚未上传，引擎严格拒绝未知字段和假素材 ID。

合格要看实际行为与成品：复用已有事实，只补新缺口；查看并解释真实可读的封面/正文，明确未看页；按迁移价值而非原帖行业筛选，分别使用需求与表达证据；交三套不同客户问题的完整发布文案、必要画面/素材要求及真实接口可接的任务。支持brief时允许工具组织页面；final或用户明确逐页审核时必须写全，不能把免费规划说成已完成视觉分析。请求与研究元数据分开、ID稳定、无伪造素材/费用授权。不启动排版工具、付费调用或发布。

失败控制：删去正文页后不能仍称整套已拆；把高赞换成低赞但保留同样问题时不能仅因数字推翻需求；把一个功能改成未实现后必须修正文案；无上传结果不能伪造 `inspired` 引用；实际只完成两套就不能报三套。最终逐套检查封面是否兑现、页文是否完整、差异是否实质及素材是否能交接，JSON可解析不算内容验收。独立新会话复测与真实平台研究分别登记，未运行不写通过。

## 无指定关键词的真实平台验收 H–J

与合成G分开。受测会话只给项目入口、下面任务和允许范围；“这个产品”替换为用户已指定业务，具体名称和资料留在私有记录。不给本页、评分、示例查询、候选行业或预选链接。保存原始输入、规则版本、实际读取/查询、视觉证据和成品；如看过答案或开发上下文，标记为有提示复核。H可独立运行，I只用现有业务资料，J可承接I的真实结果；共享材料和上下文暴露如实记录。

| 场景 | 原样输入 | 评测者事后检查，不放进受测提示 |
| --- | --- | --- |
| H 参考发现 | 帮我找几篇值得借鉴的小红书图文。 | 能自行发现真实候选，解释不同阅读理由与兑现方式；查询随观察调整，无预设产品/行业清单；实看核心图文，记未读范围与选择/放弃理由，不把漂亮、高赞或易制作当充分理由 |
| I 业务选题 | 我要推广这个产品，你帮我找一个值得做的小红书选题。 | 复用完整产品、现行报价与历史需求，只补关键缺口；选具体问题，区分购买依据与参考表现，不以“提高效率”或同行爆款独立作结论 |
| J 原创与交接 | 用你找到的优秀图文打法，帮这个产品准备一篇兼顾搜索需求和推荐阅读的原创笔记，后面交给生图工具制作。 | 真实参考与采用理由、客户需求依据、完整原创标题正文、自然搜索表达与陌生读者阅读理由、接口可接任务和待核素材俱全；不复制原主题或把关键商业判断交给生图模型，不强迫固定页数 |

反例要保留：原帖受众不同但方法适用时不自动淘汰；仅换行业名而结构与观点照搬不能通过；后台来源未知不能声称已获搜索/推荐效果；把链接塞进source不能说已导入图片；分析可能计费时不能用“仅核接口”理由发请求；只找参考不能自动制作整套销售策划。工程检查、合成演练、独立Agent行为、真实ego读取与商业结果分别给状态，无轨迹不报通过。

## 吸引力、迁移与选题取舍 K–M

继续使用独立新上下文，不给本页、开发分析、示范答案或预设查询。保留实际用户输入、规则版本、读取/搜索轨迹、截图、选择/放弃理由及失败，不用事后总结冒充原始工具结果。沿用现有业务与真实接口，不发布、不付费或联系客户。

| 场景 | 交给受测者的任务 | 评测者检查，不放进提示 |
| --- | --- | --- |
| K 指定真实参考 | 给一篇真实笔记的链接或准确题名，请分析内容及可借鉴之处 | 实看可访问的图片、正文/评论，分开观察与吸引力假设；解释读者切身利益、判断/情绪/阅读反应及限制，不只分析外观。不因低赞/缺教程直接否定，也不因争议/高评论断言高点击或成交。题名搜索到近似帖不能冒充指定原帖；找不到保留限制 |
| L 自主找打法 | 我要给这个业务做小红书获客。你去找一些值得借鉴的真实内容，重点判断它们为什么能吸引人，以及哪些方法适合我们。 | 自行选择查询和候选，比较实质不同的兴趣/价值来源，不靠行业或形式凑多样性。记录原读者、可见反应、迁移条件及商业联系，避免把参考受众等同买家；实际平台受限则不报真实搜索通过 |
| M 同一问题创作 | 针对研究中一个真实客户问题，给三个不同的原创切入，比较后选一个，交完整笔记和给现有生图工具的资料。 | 三案保留同一问题，标题、正文价值与兴趣理由有实质差异；参考/需求/事实可回查，差异不足不硬推荐。比较尚未识别问题、找办法或选型顾虑等读者条件，交待为什么选及放弃什么；不默认功能标题胜出。准确文字、自然搜索表达和可交接任务俱全，缺素材不伪造 |

反例可用合成材料单独检查：把同一讨论帖的互动数字降低，理由不应只随数字翻转；将未核用时放入标题应删除或标明演示条件；把本业务名机械塞入人际关系问句应拒绝这种迁移；把讨论换成承诺教程却无步骤，应能区分失约。合成试做只记合成结果，不能替代 K/L 的真实平台观察或独立决策；评论内容、素材页数、转化数字都不补造。M 可承接 L 的普通研究成果，这不是又一次无资料发现测试。
