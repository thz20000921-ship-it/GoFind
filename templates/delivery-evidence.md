# 图文交付单据

## 成品目录的 `visual-review.md`

按页序为每张成品原图填一行，填齐各列。文件名链接到原图相对路径，SHA256 用该原图的实际值。无问题写「无」。未取得画面时，实际看到的内容填「未取得画面」，问题填「待核」，结论填「待看」。看过的页填写具体所见和问题，结论填「能上」或「要重做」。

```markdown
# 逐页目视检查

- 对应版本
- 查看者、日期和图像工具结果或用户审核来源

| 页码 | 图片文件名 | SHA256 | 实际看到的内容 | 问题 | 结论 |
| --- | --- | --- | --- | --- | --- |
| 1 |  |  |  |  | 待看 |
```

## 发布提交目录的 `receipt.md`

一份单据对应一次提交，保存在 `publish/` 的该次提交目录下。平台确认该版本已发布后填写真实回执。提交时间带时区，截图用能打开的相对路径并与对应笔记核对。

```markdown
# 发布回执

- 对应版本
- 账号
- 平台
- 笔记链接
- 提交时间（含时区）
- 平台截图路径
```

隔离、模拟或 fixture 使用以下格式，首行从 `TEST` 开始。

```markdown
TEST/模拟。仅验证入口，不代表真实发布。

- 对应版本
- 测试回执编号及原始工具返回
```
