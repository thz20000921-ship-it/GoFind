# GoFind — AI 获客搭档

让 Codex 等能读取项目规则、具备工具执行能力的 Agent，在真实获客工作中更会调查、判断和执行。

GoFind 是可以直接打开的本地项目。专业方法来自公开原始资料，落实为调查动作、判断标准和验证办法；真实执行使用当前 Agent 已有的搜索、浏览器、连接器和文件工具。无需另接模型 API，无运行服务，无私人 Skill 依赖。

## 直接开始

1. 下载或克隆本仓库，使用 Codex 打开项目根目录并开始一个新对话。Codex 通过 `AGENTS.md` 加载项目规则。
2. 其他宿主请明确让它先读取 `AGENTS.md`。当前验证环境为 DeepSeek Harness；Codex 按官方机制应可加载，尚未实测，其余客户端未覆盖。
3. 直接说明产品和当前问题；第一次用可照下面的话术开场。

不必填写完整问卷、手动选择方法或先运行脚本。Agent 应先读取已有资料，只追问会改变关键决策的信息。没有联网工具时可以使用用户提供的真实资料、完成文案和分析，并明确哪些市场判断尚未核查。

### 第一次用时这样说

- 新业务：`新建业务：我做___，卖___给___，价格___。先按项目规则建好业务档案，再帮我查一下___。`
- 已有业务：`业务是「___」。查一下「___」这个词值不值得做，给我一条能发的笔记。`
- 续接：`继续「___」。上次在查___，今天要解决___。`
- 单次任务：`帮我把这段介绍改得让目标用户看得懂：___（这次不用建业务档案）`

合格的表现：建好 `workspaces/<business-id>/` 与 `INDEX.md`；只读 1–2 张相关知识卡；追问不超过 3 个会改变判断的问题；最后给出具体动作或成品。只改一条文案这类单次任务不应创建目录。
收尾可直接问一句：**“这次你读了哪几张卡？哪一条改变了你的结论？”** 答不出具体卡名，就是没读。

## 项目里有什么

| 入口 | 实际用途 |
| --- | --- |
| [AGENTS.md](AGENTS.md) | 宿主入口、判断原则、授权边界与长期协作 |
| [知识导航](knowledge/INDEX.md) | 按当前问题选择方法，不加载整库 |
| `knowledge/methods/` | 需求、渠道、关键词、竞品、内容、转化、定价、增长实验与复盘 |
| `knowledge/platforms/` | 各平台观察对象、证据、转化路径和常见误判；未知平台可现查 |
| [来源登记](knowledge/sources.md) | 原始来源、核查日期、可支持的说法和访问缺口 |
| [工具选择](docs/tools.md) / [证据判断](docs/evidence.md) | 怎样取得并正确理解证据，何时换工具，何时可以行动 |
| [长期协作](docs/memory.md) / `templates/` | 用普通 Markdown 保存各业务资料、证据、产出和经验 |
| [真实调查示例](examples/gofind-channel-research/README.md) | 公开资料调查、反面证据、渠道取舍、内容成品与未执行测试 |
| [检查与验收](docs/verification.md) / `scripts/check_project.py` | 可重复的项目完整性与发布前检查，场景验收办法 |

本地业务保存在 `workspaces/<business-id>/`，整个目录被 Git 忽略。每个业务只需档案、简短索引和实际做过的任务记录，按需增加附件和经验；不维护数据库。公开示例与真实业务分开。

## 专业能力怎样生效

用户问“哪个渠道值得投入”，Agent 应把用户场景、渠道证据、可达转化和资源成本放在一起比较；问“关键词有无价值”，应检查真实结果、内容匹配、咨询信号与后续验证；问“为什么没咨询”，应核对触达的人、承诺、证明、行动入口和测量口径。输出可以是一项判断、一条改好的内容或一个已执行的调查，不要求每次写报告。

所有方法明确适用条件、所需资料、工具动作、误判与验证。平台官方事实、专业方法和 GoFind 的测试假设分开，未经验证的算法传闻不作为规则。

## 工具与权限

GoFind 不预装平台爬虫，也不自带账号或商业数据权限。Agent 先按任务发现现有能力，再实际读取一次核实能否取得所需证据。专业平台会员、登录浏览器或自有后台可在授权内使用；具体工具因宿主和会话而异。公开搜索可用不代表小红书、抖音或广告后台可访问。

ego 一类的 Agent 浏览器是可选能力，执行浏览器任务时优先使用已可用的入口。[浏览器交接与取证](docs/browser.md)

调查、分析和本地草稿可直接完成。发布、对外发送、付费和高风险操作按具体授权执行。遇到访问限制会记录缺口，交付已完成部分及最短补证据办法；不把摘要或空白页面当成已读原文。
