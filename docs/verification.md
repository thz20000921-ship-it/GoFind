# 验证 GoFind 的实际表现

## 工程

```powershell
python -X utf8 scripts/check_project.py
python -X utf8 -m unittest discover -s tests -v
git diff --check
```

检查器查公开文件、入口、相对链接和常见泄密模式。单测覆盖检查器边界及图文引擎的接口、费用、失败恢复和下载校验。发布前仍要看实际改动和公开范围。

## 独立 Agent 行为

用新会话运行[行为场景](../tests/behavior-scenarios.md)。保留实际用户输入、项目快照、宿主、模型、工具、权限、原始事件、成品和文件改动。模型只看执行需要的业务资料。对照旧版、新版和裸 Agent 时，固定其他条件。检查启动指令范围和超限事件，另记方法卡实际被读取的时间。不能从超限提示推定具体截断位置。

优先比较查了哪些已经解决的问题、是否选对版本、什么事实真的改变了决定、成品能否交付，以及工具调用、时间和用量。把尺寸校验、实际图像读取、免费预检、真实生成、平台确认分别核对到回执。观察到的失败保留当次原稿和事件。工具受限、测试未执行、行为失败和通过分别记。

合成输入可复现决定，真实平台调查另按实际浏览器查询、原帖/账号读取和返回字段核验。提交中断、错账号、数据口径缺失用已有[多账号材料](../tests/fixtures/multiaccount.json)复查，真实端按[浏览器指南](browser.md)核实。

## 经营

有具体授权并发生实际动作后，回收平台或客户原件，观察一个预先选定的合格行为，记录窗口、成本和限制。自然分发或客户试用所得结果决定是否调整或扩大。上线回执只说明真实提交状态。获客判断依据下游行动、付款及履约数据。

早期真实调查与合成验收见[公开示例](../examples/gofind-channel-research/README.md)和 [V2 审查](v2-review.md)。后续各次浏览器原件和行为演练留在对应的本地忽略任务目录。
