# 按证据问题选择工具

工具选择服务于当前判断，不是每次都要完成的环境体检。所有工具名都是候选类别，实际能力以本次会话的工具声明、返回结果和用户授权为准；GoFind 不要求安装特定连接器。

## 先问“哪种资料能改变决定”

| 要回答的问题 | 更直接的数据 | 适用工具与一次有效的核实 |
| --- | --- | --- |
| 谁遇到了什么问题 | 带上下文的用户原话、已发生的替代行为 | 公开检索发现讨论，打开原帖；或读取已授权的访谈/客服记录，标记售前/购买/退款状态 |
| 搜索词有没有业务价值 | 实际搜索结果、搜索意图、咨询信号、自有查询与转化 | 平台浏览器观察原生搜索；已有关键词工具读取同地区/时段口径；自有 Search Console/后台核对查询 |
| 竞品怎么做 | 当前产品、定价条件、实际内容和行动入口 | 官方站点/平台账号/公开广告资料库；打开具体内容，区分商家主张与独立反馈 |
| 流量为什么没变成客户 | 同一时期的触达、访问、有效咨询、付款、退款和路径 | 已授权平台分析/订单工具、网页检查或导出资料；先检查一个内容到咨询/购买的完整路径 |
| 哪个内容值得做 | 真实问题、现有答案缺口、自有表现与生产约束 | 原帖/搜索结果/自有内容后台；读取原内容，核对哪些问题没回答，直接制作一份可兑现的成品 |
| GEO 是否值得投入 | 固定问题集中的答案、引用原页、实际业务流量 | 用户可用的 AI 搜索界面/合规 API，加自有访问与转化；记录引擎、模式、时间和问题，不把一次回答当排名 |

第三方专业工具适合缩小候选范围，不自动等于平台全量真实数据。先读指标定义、覆盖地区、采样、更新延迟、估算方法与导出范围。平台原生后台能证明本账号发生了什么，也不能单独证明整个市场。

## 发现能力，做最小真实读取

在宿主的可用工具列表中查找相关搜索、浏览器、平台、文件或终端能力；工具支持按需发现时使用其标准发现机制。能用现有连接器准确读取就优先用。

需要渲染页面、使用登录态或观察搜索联想、排序、评论等界面信息时，按浏览器入口顺序选择工具和降级路径。[浏览器交接与取证](browser.md)

第一次使用某个来源，只验证本任务需要的一次读取：对象是不是该账号/业务，日期和筛选是什么，结果是正文、摘要还是空壳，是否有分子/分母，是否需要额外权限或费用。不要递归扫描本机账号、配置、密钥或所有历史资料。终端找到命令只说明当前会话能解析入口，命令能否执行、连接权限、会员和登录状态须分别确认。

若会反复使用，可在该业务 `TOOLS.md` 写一行“能力 / 实测时间 / 对象 / 访问范围 / 限制 / 证据位置”。续接会话时根据新任务复核；文件中记载的可用状态不是新的执行授权。真实用过的查询和结果入口仍记在对应任务记录里。

## 原生平台观察怎样做

围绕要决定的动作列出少量候选查询；先搜一组检查意图。记录平台、原样查询、地区、登录/未登录、排序、筛选、时间窗口和观察时间；需要复查时保存脱敏截图或原链接。结果重合则去重，保留普通和不符合预期的内容，避免仅采热门。不要为达成固定样本数无意义翻页。

看到购买语句，回到上下文：是在提问、给别人推荐、已经购买，还是营销账号自问自答？没有原文或身份核实，不给“真实买家”标签。付费工具给出的“预估销量”“热度”“搜索指数”按工具口径记录，不转成实际客户人数。

## 访问受限时的具体动作

| 实际返回 | 能说什么 | 接下来做什么 |
| --- | --- | --- |
| 搜索摘要可读，原页打不开 | 搜索工具在此时展示了该摘要 | 记录 `仅摘要`，它只作线索；若关键判断依赖原页，再尝试已有授权浏览器或同一原始来源的公开说明 |
| 需要登录、会员、验证码或权限 | 本次未取得目标资料 | 在现有授权内交给用户登录或提供导出；不换账号绕过、不自动购买会员 |
| HTTP 返回 200，但正文为空或极短 | 正文未取得，常见原因是页面依赖 JavaScript 渲染 | 改用渲染型浏览器或用户截图，不据此断言页面无内容 |
| 返回零条或空白正文 | 本次查询/工具未取得记录 | 检查查询、筛选和工具覆盖；不据此断言市场无需求或页面没有内容 |
| 被限流、平台禁止、接口未授权 | 该获取路径当前不可用 | 停止该路径，说明对结论的影响；利用已有证据完成草稿/判断或设计小测试 |

需要用户配合时一次说明：解决哪个决定、具体账号/页面、查询/筛选、必须取得的字段、记录来源与时间的方法、怎样脱敏交回、取得什么就足够。不要让用户漫无目的截图，也不要让所有任务都变成“请先提供数据”。

## 安装与新增工具

只有现有能力确实缺少关键证据时才调查新工具：核对官方文档、可信发布者、权限、费用、数据保留和平台许可；优先最小范围的真实读取。已授权范围内的普通工具使用继续执行；新增账号权限、付费或外发数据先确认。安装不等于已经验证业务结果，不为工具完整性而集成工具。

数据分析工具的公开实现参考见 [S22–S25](../knowledge/sources.md#工程与工具实现参考)，属于可选能力，均不是本项目依赖。
