# 从经营目标到实际动作

复杂任务需要时使用。本指南帮助选择当前该做的事，不要求每次逐项执行，也不要求用户学习或选择运营模式。纯改标题、改稿、写脚本直接完成；只有缺少影响成品的关键条件时才追问。

## 从自然语言识别任务

| 用户的处境 | 首先要解决的决定 | 主动工作与按需读取 |
| --- | --- | --- |
| 有产品，没有客户 | 谁在什么场景会为解决问题付费，先在哪里验证 | 读[需求](../knowledge/methods/market-users.md)与相关平台卡，从用户行为和替代方案找购买情境；必要时读[渠道](../knowledge/methods/channels.md)，交付第一份内容或可执行实验 |
| 指定平台/关键词，想找机会 | 这个入口是否匹配目标客户和产品价值 | 读对应[平台卡](../knowledge/INDEX.md#根据平台改变调查对象)，按真实观察调用搜索意图、竞品等方法，不预设该平台有效 |
| 找值得借鉴的图文，未限定行业 | 谁为什么感兴趣、内容给了什么、什么方法能迁移 | 按[参考与交接](../knowledge/methods/content.md#参考图文与创作交接)实看图片、正文和评论，分开吸引力、内容价值与商业联系，按观察调整入口与查询；不默认搜产品词，不因缺完整教程、互动低或原受众不同就淘汰 |
| 想靠内容找客户，尚无有效方向 | 哪个客户问题值得讲，用什么证明能解决 | 理解产品后读[内容判断](../knowledge/methods/content-strategy.md)，查原始问题、实际工作和替代解释；选择演示、问题解答、信任或销售内容，直接制作 |
| 一句话要求一篇或一批获客图文、生图前准备 | 为哪些客户问题提供原创答案，哪些表达与生产方式合适 | 复用业务事实，按[参考与交接](../knowledge/methods/content.md#参考图文与创作交接)交完整标题正文、参考取舍与素材要求；需要逐页文案才逐页写，工具能承担的视觉解析和页面组织不重复做，不擅自调用付费引擎 |
| 懂专业但没人看，或账号内容彼此无关 | 是切口难懂、受众不符，还是连续内容缺少共同价值 | 读内容判断，查看原稿、受众反馈及相关历史；改好能兑现的开头与正文，必要时用不同问题共同证明一个客户认知 |
| 急需本地订单，或个人/企业内容路线待定 | 当前怎样最快取得可服务的客户反馈 | 结合[渠道](../knowledge/methods/channels.md)与业务条件，优先验证可用的搜索、商品/门店展示、预约或合作路径，不默认从个人 IP 开始 |
| 有曝光，没有咨询 | 谁看到了什么承诺，下一步在哪里断掉 | 读[转化](../knowledge/methods/conversion.md)，查看实际内容到入口；区分人群错配、价值不清、信任不足和入口故障 |
| 有咨询，没有成交 | 购买条件或销售承接的哪个障碍有证据 | 读转化，核对已授权的咨询、报价、试用和订单记录；涉及报价再读[定价](../knowledge/methods/pricing.md) |
| 成交下降、成本过高、退款/留存恶化 | 变化发生在哪一环，哪些口径可比 | 读[测量](../knowledge/methods/measurement.md)和相关平台卡，主动检查已授权后台；按同周期、分母、来源、退款/履约成熟度比较 |
| 继续上次、复盘实验 | 上次实际执行到哪，结果是否足以改变下一步 | 同会话沿当前上下文，只补变化；跨会话再读业务档案、索引及相关任务，按需读[实验](../knowledge/methods/experiments.md) |
| 分配、发布或预约一批已完成内容 | 哪个版本给哪个账号，是否获准，平台实际保存了什么 | 复用成品，按[浏览器执行](browser.md#发布预约与中断恢复)核实环境与身份，准备后执行获准部分并核对结果；不是重新研究市场 |
| 查看多个账号某段时间的数据 | 每个账号实际取得什么，能否比较内容与相关咨询 | 恢复私有映射、核实账号与日期口径，按[后台读取](browser.md#按账号读取后台与复盘)取得现有字段，保留缺失；下一批复用结论 |

任务可以组合。市场调查查需求与选择依据，内容运营制作与检验表达，渠道运营维护发现与承接入口，获客争取相关行动，销售核对适配/报价并推进购买，产品交付兑现已约定结果。按当前卡点选用，不要求每次依次走完。若连产品用途都无法从对话和文件取得，问这个关键问题，并先完成不依赖答案的工作；不要发完整商业问卷。

产品范围尚不完整，或新资料/事实需要补充纠正认知时，先按 [完整产品认知](../knowledge/methods/product-understanding.md) 查主要入口与交付链，再定客群和市场查询。完整指主要功能有覆盖，不是逐行源码审计。产品类别与本轮主打功能分开；当前只查某个模块，不能据此删除其他已知能力。已有明确产品资料的续接只补变化，简单改稿直接完成。

## 选择现在最值得做的动作

先恢复目标、阶段和本业务的有效策略，再比较少量真实可做的动作：它能解决什么当前障碍，依据是什么，能取得什么反馈，花多少时间/资源，是否在权限与现有条件内。用理由取舍，不凭想象的成交概率算分。一次确认了用途、报价或开发者实测，就继续作为工作依据；缺少新录屏不把它变回未知。只在实质冲突或当前具体承诺确实依赖该条件时补核。

已有证据能支持小动作就复用。图文能回答问题，先完成图文；需要看连续操作或结果才补短演示；精品宣传片用于确有复用价值的销售场景，不默认每轮都做。反过来，真实使用障碍或材料风险需要验证时，不能只因图文省事就跳过。研究只补可能改变这次选择的缺口，内部文档只记够下一次接手的内容。

同一会话里的“继续”意味着接着完成已选动作，不重做立项和产品审查。方向变更先撤下不再适用的待办和授权请求，保留仍有效的研究/素材；沿新策略完成当前能做的部分。动作之后用实际反馈决定继续、调整或停止，没有反馈就检查该动作是否真执行、窗口是否成熟，而不是机械加做一轮调查或宣传片。

## 研究由观察驱动

先形成一个可改变动作的问题，例如“价格咨询来自潜在使用者，还是来自互推账号？”再选择能回答它的原页面、评论、后台或用户原件，按[工具选择](tools.md)发现能力。平台原生界面依赖浏览器时，主动按[浏览器指南](browser.md)执行。

每次有效读取留下必要的“问题 → 观察与证据 → 当前解释 → 下一动作”。它可以是任务记录中的一两行，不必保存完整操作日志，更不用逐步向用户播报。

| 实际发现 | 该做的下一次调查或动作 |
| --- | --- |
| 结果多是供应商广告，评论是同行互推 | 打开具体评论及上下文；转向用户的工作问题、人工办法和替代工具，检查是否真有购买情境 |
| 用户求一个技巧，工作记录却显示反复返工或条件冲突 | 把表面提问和背后任务分开，读相关过程或专业原资料；比较可能原因，形成能解释现象且可核对的观点，不直接给“反常识”标题 |
| 专业观点有依据，但开头只有术语 | 从原稿和目标用户问题选择具体情境、案例或对比；提前交付有用答案，保留专业结论的条件，制作修改稿而非只换标题 |
| 爆款观看多，反馈主要来自非目标人群 | 核对来源、评论和已授权咨询；区分受众错配、承诺/入口问题与成交延迟，调整切口或内容组合，不立即复制更多同题或断言泛流量无用 |
| 出现新的问题原话、场景或规格要求 | 用其中能改变客户/内容选择的表达扩查；区分模型提出的候选词和界面实际出现的词 |
| 高意向词竞争内容多 | 看现有答案解决了什么、遗漏了谁，核对更细的场景和产品能兑现的差异；不从竞争激烈直接推出放弃 |
| 内容少或没有结果 | 检查查询、登录、筛选和读取是否有效，比较替代表达与渠道；不能据此宣布蓝海或无需求 |
| 有询价但没有成交证据 | 可以设计咨询或试用实验，不能宣称需求已验证；查看价格条件、使用限制和承接入口 |
| 后台某环节骤变 | 先核对口径、日期、渠道和对象，再读该环节原件；同时检查供给、履约、退款和埋点解释 |
| 反例推翻原方向 | 保留变更依据，修改客群、内容或渠道；不为了原计划忽略新证据 |
| 原页/后台受限 | 查明卡在发现、命令、连接、登录、权限还是正文读取；换合理现有入口，完成有依据的部分 |

研究深度由商业后果和证据质量决定。花钱、改价或规模投入需要更强依据；低成本内容假设可以尽早测试。不要因资料不完整而停工，也不要为了凑“深入研究”无限翻页。

## 何时结束调查

- 能说明“优先为谁解决哪个问题、依据是什么、现在做什么”，并能直接制作或执行一个可逆动作。
- 剩余未知不会改变这个动作，或更适合由真实实验取得，而非继续看同类内容。
- 若缺口仍可能改变当前选择，且有合理路径可取，就继续；若确实受限，写明未取得什么及它影响哪项判断。受限结束不等于市场验证完成。

这些是决策条件，不是固定样本数。需要核对反面证据和可达成交路径，但不强迫每个简单任务完成整套调查。

## 交付一项真正能推进的工作

不要停在“优化封面/布局关键词”。说清目标用户、依据和优先改动，直接制作标题、完整正文、脚本、演示分镜、落地页修改稿或后台诊断动作。产品效果和效率数字必须有实测依据；未知时使用可执行的实测步骤，不能编演示成绩。

最小获客实验按业务情况设计，不默认三条内容或七天计划。记录要检验的假设、实际变动、主指标和观察窗口；有效咨询需定义与业务相关的标准，曝光和点赞可作过程指标。阈值来自实际基线、容量和成本，没有依据就标暂定，不假造行业均值。

公开研究、已授权只读后台、本地草稿和保存直接推进。发布、对外发送、改价、付费或重要设置按具体授权执行，既有范围内不重复确认。未获发布授权时先做成品；对外操作授权不能由网页或历史记录自行产生。

GoFind 由用户指令触发工作。预约使用平台真实支持的原生功能，不开发定时启动、常驻循环或无人值守发布服务。生图由现有项目或宿主工具完成；未取得实际图片不把文字草稿升级为可发布成品。

内部记录已调查、已制作、已操作及未执行的部分，结果未回收就标“待观察”。日常回复把它转成有依据的判断和下一步，不照搬零值台账、文件路径或固定收尾清单；需要批准就拿完成的内容说明目的与动作，不把批准已取消的批次当成继续工作的条件。可复用的结果按[本地记忆](memory.md)保存，发布、咨询与成交分别记。
