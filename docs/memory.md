# 用文件延续业务，不把所有内容塞进上下文

本地记忆依靠 Agent 的标准文件读写与搜索，不需要数据库、额外模型或私人 Skill。没有实际需要保存的短任务可以直接完成；有价值的事实、判断、产出和结果才进入记忆。

## 一个业务的最小目录

```text
workspaces/<business-id>/
  PROFILE.md                 # 产品、用户、目标、资源、边界；标明资料状态
  INDEX.md                   # 每个有价值任务一行：日期、问题、发现、路径、复查条件
  tasks/2026-11-10-短主题.md   # 同一任务里的证据、判断、产出、执行与复盘
  tasks/2026-11-10-短主题/     # 仅在需要截图/导出等附件时建立
  LESSONS.md                 # 仅在有经验值得复用时建立
  TOOLS.md                   # 仅在需要复用工具入口时建立；不保存登录信息
```

`business-id` 选稳定、简短的目录名；业务中文名称写在档案中。不同业务的资料不互相复制为事实。共性经验可以抽象成方法，但去掉身份信息，并注明原来适用的条件与新业务尚需核查的地方。

首次建立时由 Agent 从 [业务模板](../templates/business.md) 写入已知内容；不要求用户手动建目录。索引和任务可以直接写，或使用 [任务模板](../templates/task.md) 的相关段落；不保留不适用的空栏目。用户已允许本地持久化时直接保存，不逐项请求同一范围的许可。

## 开始新任务时读什么

先确定业务，再读 `PROFILE.md` 和 `INDEX.md`，按当前问题只打开 1–2 份任务记录；有更新任务时优先读更新。不通读 `tasks/`。没有历史资料就直接工作，不伪造“根据过往经验”。

对经验重新判断适用性：产品/客群/价格/平台规则/履约或测量方式变了吗？规则和平台现状在依赖它们作新决策前复核；一次实验结果是历史事实，有效性外推仍是推断。日期较新也不自动代表可靠。

## 任务结束后留下什么

任务文件中给重要结论引用证据 ID，明确实际已执行、仅完成草稿、待授权或当前受限。内容产出直接写入任务或链接业务目录内的成品。保留必要原件、来源、观察条件和缺口即可，不沉淀整页低价值搜索结果。

`LESSONS.md` 每条包含“方法 / 适用条件 / 实际结果与证据 / 反例或混杂 / 暂定或重复支持 / 复查触发”。一次成功先标暂定；多次成功仍不能自动跨平台外推。被否定的经验加失效原因和日期，索引指向新结论，不能只删掉失败记录。

## 写什么、不写什么

记忆的目标是“下一次还能用”，不是“这次全留”。

| 值得写 | 不值得写 |
| --- | --- |
| 业务事实：产品、客群、价格条件、可服务范围 | 完整聊天记录、对话原文粘贴 |
| 一次任务的来源、观察条件、口径与截图 | 整页网页归档、整份后台导出 |
| 已验证事实 / 分析推断 / 待验证假设 | 反复推翻的中间草稿 |
| 可直接使用的成品：标题、正文、脚本、报价 | “我打算写一个……”的计划 |
| 结果与未执行项：发了没发、测得没测 | 同一结论换三种说法 |

拿不准时只问一句：这条会改变下一次任务的某个决定吗？不会就不写。

## 一次任务只更新三处

1. `PROFILE.md`：业务事实变了才改（价格、客群、可服务范围、授权边界）。
2. `INDEX.md`：加一行——`日期 | 问题 | 结论与状态 | 任务路径 | 复查触发`。
3. `tasks/<date>-<主题>.md`：这次任务的证据、判断、成品与未执行项。

三样都写不成，说明这次任务本不值得记，直接结束。不为凑结构建空文件、空小节；[任务模板](../templates/task.md) 按需删减。

## 索引不长胖

历史结论是历史事实，不外推为当前结论。索引长到无法一眼扫完时，先合并同类项；已失效的行标为“已失效（原因、日期）”，半年未复查且不再影响动作的记录移到 `tasks/archive/`，索引留一行指向新位置。标记和归档可保留判断依据，直接删除会丢掉它。

## 保存的边界

`workspaces/` 和 `private/` 全部被 Git 忽略；任何真实业务、未发布素材、工具导出和授权记录都放这里。不要在项目根目录随手保存客户数据；外部来源中的访问令牌和联系方式也要去除。公开示例只含主动选取的公开、非敏感信息，不从私人业务自动导出。

这些目录没有加密，也不会自动云同步。用户需要备份时按明确选择的备份位置操作；复制整个项目到另一台电脑可连同这些本地文件迁移，公开仓库的普通克隆则不包含它们。不要把“Git 忽略”说成已备份或绝对不会泄漏；被强制添加的文件仍可进入 Git。
