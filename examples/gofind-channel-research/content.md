## 图文正文

标题：**Agent 说“这里有客户”，先看它到底查到了什么**

封面文字：**一条“市场需求”，可能只是 Agent 的自我介绍**

正文：

我在做 GoFind，一个让现成 Agent 参与真实获客工作的本地项目。今天先拿自己的方向做了一次公开资料调查。

搜“营销 Agent”，已经能看到不同供给：有按任务组织营销能力的项目，有连接业务数据做分析的，也有围绕广告账户工作的。只写“AI 帮你营销”，还不足以让人知道为什么要选 GoFind。

更容易误判的是需求信号。

我找到一条谈中国服务商户和多平台获客的公开帖子。打开原文，它自称 Agent 代表团队交流；另外两条改进建议来自维护者本人，其中一条已经关闭。

这些内容有参考价值，但不能算成三位独立客户，更不能写成“付费需求已验证”。当前工具也没读到小红书相关官方页面的正文，因此这次没有小红书关键词量、笔记评论或客户样本结论。

GoFind 想把这几件事做好：能调查的就实际调查，重要判断保留出处，事实、推断和假设分开；证据够了就做具体内容或小测试，资料拿不到就说明缺口。

这次得到的动作是：先把可复现调查案例和使用入口做好，再验证真实使用价值。没有把“研究了几个项目”写成“已经找到了客户”。

你也可以检查一次自己的获客分析：它引用的是客户做过的事，还是别人对市场的描述？

来源供核查：[调查证据](evidence.md)。若移到外部平台发布，应附实际可访问的公开来源入口；当前相对链接只适用于本地项目。

## 视频拍摄脚本

这是可拍摄的脚本，**镜头尚未录制**，时长按讲述节奏调整，不宣称最佳平台时长。

| 口播 | 画面/字幕 |
| --- | --- |
| “Agent 告诉你这里有客户，先问一句：它到底查到了什么？” | 项目中的调查问题与三个结论标签：事实、推断、假设 |
| “我做 GoFind 时查到一条中国市场相关帖子，看起来像需求。” | 实际打开的 #325 页面；只截相关段落，隐去无关身份信息 |
| “打开原文，它自称 Agent 代表团队。另外两条建议来自维护者，其中一条已经关闭。” | 相关标题/状态和本地证据记录，字幕：线索 ≠ 独立客户 ≠ 付款 |
| “这些线索可以帮我们继续查，但不能写成需求已经验证。” | 三列：实际读到 / 当前解释 / 下一次要验证 |
| “这次我先把可复现案例和使用入口做好。有没有真实使用价值，还要看实际任务。” | 本地 README、方法入口与这份完整调查 |
| “下次看获客分析，检查它的来源有没有真的支持结论。” | 明确收束到观众可做的一步；不放不存在的购买/下载链接 |

素材来自本次公开原件和本地项目，录制前复核页面是否变化及素材展示条件。不截账号后台、客户身份或会话密钥；不伪装成已经录好的演示。

## 选题备选与假设

这些是根据当前问题制作的备选，**未经搜索量或分发效果验证**：

- “关键词内容少，为什么还不能叫蓝海？”——面向容易把供给缺口当需求的人。
- “只拿播放量复盘，为什么可能越做越偏？”——面向目标是咨询/成交而非泛曝光的人。
- “给 Agent 一个真实获客问题，它应该留下哪些证据？”——用于演示从查询到内容成品。

是否在小红书、视频号或开发者社区使用，取决于后续真实人群调查和账号条件；不能把同一成品直接称为所有平台都适配。
